# 产品定位

## 一句话

metablog 是一个**存元认知的地方，主形态是博客**：把「我是怎么想的、哪里想错了、后来怎么看」写成一篇篇博文，长期积累、回看、提炼，愿意的话发出去。

## 元认知指什么

元认知是「对自己思考的认知」。在 metablog 里，它具体是这几类内容（对应博文的 `kind` 字段）：

| kind | 是什么 | 例子 |
|---|---|---|
| 复盘 | 一件具体的事：当时怎么想、结果如何、现在怎么看 | 「一次三小时的方向性错误」 |
| 觉察 | 发现了自己的一个思维习惯或偏差 | 「我为什么总是高估自己读懂了」 |
| 方法 | 一个自己验证过、管用的思考方法 | 「每读完一节，合上书写三句话」 |
| 提问 | 一个还没想清楚、但值得记下的问题 | 「我到底什么时候该停下来重新想方向」 |

不在范围内的：知识笔记（书讲了什么）、日记（今天发生了什么）、待办。它们可以作为**素材**（origin）存进来，但只有对它们的**反思**才是 metablog 的主体。

## 为什么是博客

- **写成文章逼人想清楚**。一条笔记可以含糊，一篇有标题、有「当时怎么想 / 现在怎么看」的文章不行。
- **元认知有时间维度**。同一件事三个月后再看，看法常常变了；而「看法怎么变的」本身就是元认知。博客天然按时间排，再加上只增的**后记**，能把这条变化线留下来。
- **可以发出去**。公开写作是一种外部检验；但元认知很私人，所以发布是逐篇选择，默认不发（见 [publish.md](publish.md)）。

## 给谁用

v1 是**单人**工具：一个人在自己机器上写、读、回看。作者取 git author。没有账号、权限、多人协作（见 [codebase.md](../../structure/v1/codebase.md) 里「没借什么」）。

## 核心循环

```
素材 ──写──▶ 博文 ──隔段时间回看──▶ 后记
                │
                ├──── 几篇反复印证 ────▶ 条目（insight）
                │
                └──── 选择公开 ────▶ 静态站 / RSS
```

每一步的具体动作见 [workflows.md](workflows.md)。

## 不做什么（v1）

| 不做 | 为什么 |
|---|---|
| 数据库、搜索索引 | 内容就是 git 里的文件；检索用 `git grep`。见 [storage.md](storage.md) |
| 多人、账号、权限 | 单人工具，用不上 |
| 在线评论、读者互动 | 发布是静态导出；互动以后再说 |
| 自动从对话里生成博文 | 元认知要自己写才算数；AI 能参与到什么程度见 [open-questions.md](open-questions.md) |
| 跑 agent 的工作台 | memory.talk 有，metablog 不需要 |
