# docs

| 目录 | 讲什么 |
|---|---|
| [`designs/v1/main.md`](designs/v1/main.md) | **为什么**：metablog 的整体定位（资料库 + 博客）、资料库收什么、还没定的事 |
| [`structure/v1/`](structure/v1/README.md) | **是什么**：对象、字段、磁盘布局、代码仓库布局（还是三层旧模型，待对齐） |

## 约定

- **一件事只在一处写**。designs 讲理由，structure 讲定义，互相引用，不重抄。
- **没有占位文件**。还没设计的东西不建空文件，记在 main.md 的「还没定的事」里。HTTP API（`api/`）和命令手册（`cli/`）等接口定下来再加。
- **版本**：按 `v<N>/` 分版本。v1 定稿前直接改，定稿后不兼容的改动开 v2。
