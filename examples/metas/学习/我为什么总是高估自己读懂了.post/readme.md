## 发生了什么

读完一章觉得都懂了，第二天想给同事讲，讲不出来。

## 我当时怎么想的

每一段都读得很顺，没有卡住的地方，于是默认自己理解了。

## 现在怎么看

「顺」只说明文字好读。理解要看能不能用自己的话重讲、能不能举出书上没有的例子。

## 下次怎么做

每读完一节，合上书写三句话。写不出来就重读。
