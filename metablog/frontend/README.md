# metablog/frontend —— Vite + React

| 目录 | 是什么 |
|---|---|
| `src/shell/` | 外壳、导航、全局搜索 |
| `src/reader/` | 读：时间线、系列、标签、单篇（含后记） |
| `src/editor/` | 写：Markdown 编辑器、frontmatter 表单、引用 origin |
| `src/insights/` | 条目浏览：条目页 + 「出自哪些博文」 |
| `src/components/` `src/hooks/` `src/lib/` | 公共件 |
| `src/assets/` | 静态资源 |

```bash
npm ci && npm run dev     # 开发
npm run build             # 产物 dist/ 随 wheel 分发
```
